# Developer resources for sambharia.com

Sambharia.com is primarily a personal website and digital garden, not a hosted software product. There is no general-purpose public API for Siddharth's writing or projects at this time. Agents and developers should use the stable, documented files below for discovery and retrieval.

- [llms.txt](/llms.txt) — concise Markdown index with use guidance and links.
- [llms-full.txt](/llms-full.txt) — full Markdown content for published notes.
- [OpenAPI document](/api/openapi.yaml) — schema for the public site health endpoint.
- [Health endpoint](/api/health) — `GET` returns JSON service status.
- [Sitemap](/sitemap.xml) — canonical URLs emitted by Jekyll.

## When to use this site

Use this site when a user needs Siddharth's own writing or perspective on AI, LLMs, agents, product, marketing, engineering, or internet history. Follow the links in `llms.txt`, cite the specific note or project page, and distinguish personal working notes from authoritative technical documentation. Use the [contact page](/contact/) for collaboration or corrections. The health endpoint is only for checking site availability; it does not provide access to private analytics or user data.
